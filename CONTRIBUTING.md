# Изменения в проекте

Это небольшой учебный проект. Для предложения исправления создайте issue с шагами воспроизведения или pull request с описанием проблемы.

Перед отправкой выполните:

```sh
python -m unittest discover -s tests -v
node --check monitor/static/app.js
```

Если меняете поведение, добавьте тест соответствующего сценария. Коммиты называйте по-русски и описывайте конкретное изменение, например «Исправил расчёт доступности без проверок».

Не добавляйте в репозиторий рабочие базы, логи, токены и содержимое личного окружения.
