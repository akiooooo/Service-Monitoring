# Использование ИИ

В подготовке проекта использовался ИИ-помощник: для обсуждения темы и интерфейса, проверки кода и документации. При финальной проверке помощник также участвовал в исправлении обработки ошибок планировщика, добавлении регрессионных проверок и подготовке материалов для сдачи.

Поэтому помощь не ограничивалась только дизайном. Наличие тестов не означает, что автор автоматически понимает каждую строку. Перед защитой нужно самостоятельно разобрать HTTP-запрос, планировщик, запись в SQLite, расчёт доступности и обработку инцидентов.

Эта заметка описывает подтверждённое участие помощника в текущей проверке и не устанавливает происхождение каждой строки прежней версии.
