# Проверка перед сдачей

Дата: 12 ноября 2026 года.

## Что проверяется автоматически

- Успешный HTTP, ошибка 503, редирект без перехода и таймаут.
- Создание, изменение, поиск, фильтры и удаление сервиса.
- Сохранение истории, каскадное удаление, инциденты и восстановление.
- Процент доступности за выбранный период и защита CSV от формул.
- Пауза, ручная проверка и запрет параллельных проверок одного сервиса.
- Освобождение занятой проверки при ошибке базы и повтор планировщика после сбоя SQLite.

Команда: `python -m unittest discover -s tests -v`.

В финальной локальной проверке на Python 3.13 прошли все 9 серверных тестов.
Проверка Chromium также прошла; снимки desktop и мобильного экрана сохранены в `docs/screenshots`.

## Дополнительная проверка

`node --check monitor/static/app.js` проверяет синтаксис JavaScript. Скрипт `scripts/check_ui.py` проверяет интерфейс в Chromium на отдельной временной базе и локальном демо-сервисе. Playwright нужен только для этого скрипта и не требуется для запуска приложения.

GitHub Actions проверяет серверные тесты на Windows и Ubuntu с Python 3.11–3.13.

## Ограничения

Это локальное учебное приложение, без авторизации. Оно умеет проверять внутренние адреса, поэтому открывать API в интернет нельзя. Поддерживаются только HTTP/HTTPS, проверяется код ответа, тело не анализируется. Доступность считается по результатам проверок, а не как точный SLA. История не очищается автоматически. Уведомлений нет.

Автоматическая публикация заранее подготовленных изменений отключена в финальной версии. Ранее такая очередь использовалась; история сохранена, а перевод английских названий коммитов не меняет их содержимое.
